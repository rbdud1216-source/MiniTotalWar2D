# 🏹 화살 시뮬레이션 시스템 (ArrowSimulationManager & Ballistics Engine)

## 💡 핵심 요약 & 역할 (Summary & Role)
- **책임 영역**: 수천 발의 화살 투사체를 유니티 내장 물리 엔진(PhysX) 부하 없이, 뉴턴 역학 기반 물리 탄도학 공식과 GPU 인스턴싱(`DrawMeshInstanced`)으로 초고속 연산·렌더링하고, 아군 차폐 시 고각 곡사 및 착탄 대미지를 가하는 전역 화살 시뮬레이션 엔진.
- **핵심 특징**:
  1. **동일 에너지 기반 탄도각 자동 산출**: 동일한 발사 속력(v0) 가정 하에, 가까우면 0도(직사), 멀어질수록 45도(표준 곡사)로 자동 계산.
  2. **전방 아군 차폐 감지 및 고각 곡사 (48도 ~ 75도)**: 발사 방향 전방에 아군이 있거나 후열에 위치할 경우, 아군 오사를 방지하고 머리 위를 넘기기 위해 고각 곡사로 발사.
  3. **뉴턴 물리 법칙 완전 구현**: 비행 중 실시간 수직 속도 공식(`v_y = v_0y - g * t`)을 적용하여, 최고점 부근에서는 수직 속도가 0이 되어 감속되고, 낙하할 때는 중력 가속도로 빨라져 착탄 시 최대 속도로 지면에 꽂힘.
  4. **Job 동기화 및 안전성 완벽 보장**: 메인 스레드 수동 틱(`ManualUpdate`)과 방어적 `Complete()` 호출로 `InvalidOperationException` 원천 차단.
  5. **순수 ECS(Pure ECS) 듀얼 모드 지원**: GameObject 모드뿐만 아니라 순수 ECS 모드에서도 Sphere 메쉬 렌더링 및 150m 사거리 화살 발사 완벽 지원.

## 🛠️ 5. 핵심 알고리즘, 물리/전투 수학 공식 & 조작법 (Algorithms, Math & Controls)

### 1. 동일 에너지(일정 속력 v0) 기반 탄도각 산출 공식
- 수평 거리 R, 초기 속력 v0, 중력 가속도 g (9.81 * gravityScale)
- 필요 기본 저각 (Low Arc):
  `sin(2 * theta) = (g * R) / (v0 * v0)`
  `thetaLow = 0.5 * arcsin(clamp01((g * R) / (v0^2)))`
  - 거리가 가까우면 (R -> 0): `thetaLow -> 0도` (직사 / 평사)
  - 거리가 멀어지면 (R -> R_max): `thetaLow -> 45도` (표준 곡사)

### 2. 일제사격 화살 다발(Volley Bundle) 및 행별 미세 분산
- 모든 병사가 부대 공통 기준 탄도각을 공유하여 하나의 웅장한 화살 다발을 형성.
- 사수의 행 인덱스(`shooterRow`)에 따라 행당 약 1.2도(`clamp(shooterRow * 1.2도, 0도, 6도)`)의 미세 고각 분산(Rank Offset)을 가산하여 화살들이 겹치지 않고 자연스럽게 호를 그리며 비행.
- 전방 적이 아군과 백병전 중일 때만 부대 전체가 아군 머리 위를 넘기는 48도 ~ 75도 고각 곡사로 전환.

### 3. 3축 공간 및 사선 클리어런스 판정 공식
1. **후방 검사**: 최후열(`Row >= totalRows - 1`)이거나 견착 무기(`minRearSpacing == 0`), 또는 부대 세로 간격(`squadSpacingZ >= minRearSpacing`) 시 통과.
2. **측면 검사**: 부대 가로 간격(`squadSpacingX >= minLateralSpacing`) 시 통과.
3. **전방 사선 및 언덕 경사면 검사**:
   - 1열: 무조건 통과.
   - 체커보드 2열: 틈새 직사 허용 시 통과.
   - 3열 이상 또는 직렬 2열:
     - 앞열 간격: `distToFront = Row * max(0.5, squadSpacingZ)`
     - 언덕 지면 고도 우위: `slopeDy = (shooter.y - enemy.y) * (distToFront / distToEnemy)`
     - 탄도 앙각 고도: `elevationDy = distToFront * tan(baseAngle)` (곡사: 15°~35°, 직사: 약 2°)
     - 총 여유고: `totalClearance = slopeDy + elevationDy`
     - 판정: `totalClearance >= headClearanceMargin` 충족 시 사격 허용!
     - 평지 직사 무기(총/쇠뇌)는 1열만 사격하지만, 가파른 언덕 고지대에서는 `slopeDy`로 인해 후열도 전열 일제사격 개방!

### 4. 뉴턴 물리 역학 공식 (최고점 감속, 낙하 가속)
- 초기 속도 분해:
  - 수평 속력: `v_horiz = v0 * cos(theta)`
  - 수직 초기 속력: `v_0y = v0 * sin(theta)`
- 실시간 비행 위치 (경과 시간 t):
  - 수평 위치: `x(t) = start.x + dir_xz * (v_horiz * t)`
  - 수직 높이: `y(t) = start.y + (v_0y * t) - (0.5 * g * t^2)`
- 실시간 속도 벡터:
  - `v_y(t) = v_0y - g * t`
  - `velocity(t) = dir_xz * v_horiz + up * v_y(t)`
  - **감속/가속 메커니즘**:
    - 상승 구간: `v_y > 0`이지만 지속 감소하여, 최고점에서 `v_y = 0`이 되어 전체 속력이 최소(`v_horiz`)로 감속.
    - 하강 구간: `v_y < 0`이며 중력 가속도로 빨라져 착탄 순간 최대 속력(`sqrt(v_horiz^2 + v_y^2) ≈ v0`)으로 내리꽂힘.
