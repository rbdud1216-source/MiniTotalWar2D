# 🏹 화살 시뮬레이션 시스템 (ArrowSimulationManager & Ballistics Engine)

## 💡 핵심 요약 & 역할 (Summary & Role)
- **책임 영역**: 수천 발의 화살 투사체를 유니티 내장 물리 엔진(PhysX) 부하 없이, 뉴턴 역학 기반 정통 물리 탄도학 공식과 GPU 인스턴싱(`DrawMeshInstanced`)으로 초고속 연산·렌더링하고, 동일 발사 속력 기반 직사/곡사 분기 및 비행 중 공기 저항(항력) 감속을 적용하는 전역 화살 시뮬레이션 엔진.
- **핵심 특징**:
  1. **초기 발사 속력(v0) 100% 완전 일치**: 직사(Flat)든 곡사(High Arc)든 유닛에 설정된 고유 발사 속도(`projectileSpeed`, 기본: 30m/s) 크기를 100% 동일하게 유지.
  2. **정통 포물선 궤적 방정식의 이중근 (Low Arc & High Arc)**: 목표 거리(R), 고저차(diffY), 초기 속력(v0), 중력(g)으로 탄도학 방정식의 두 근을 풀어 직사(저각 해)와 곡사(고각 해)를 명쾌하게 분기.
  3. **선형 공기 저항(항력, Drag) 감속 엔진**: 비행할수록 지수 감속(`v(t) = v0 * exp(-k * t)`)을 적용하여, 날아갈수록 속도가 줄어들며 목표 지점에 묵직하게 꽂히는 현실적인 화살 비행 연출.
  4. **오차 0.000m의 O(1) 해석해(Closed-form)**: 프레임 루프 적분 없이 시간 t만 대입하면 즉시 3D 위치와 접선 속도 벡터가 계산되므로 2,048발 사격 시에도 CPU 부하 0% 유지.
  5. **전방 아군 차폐 감지 및 고각 곡사**: 전방에 아군 백병전 전선이 있거나 언덕 너머 사격 시 자동으로 고각 해를 채택하여 아군 머리 위를 안전하게 통과.
  6. **Job 동기화 및 듀얼 모드 완벽 지원**: GameObject 모드(`UnitJobSimulationManager`) 및 Pure ECS 모드(`UnitCombatAndMovementSystem`) 1:1 완벽 호환.

## 🛠️ 5. 핵심 알고리즘, 물리/전투 수학 공식 & 조작법 (Algorithms, Math & Controls)

### 1. 상하 90도 전방위 포물선 궤적 방정식 및 수직 특이해 (-89.5도 ~ +89.5도)
- 목표 수평 거리 R, 고저차 diffY, 초기 발사 속력 v0 (projectileSpeed), 중력 g (9.81 * gravityScale)
- **수직 특이해 분기 (R < 0.2m)**:
  - 수평 거리 R이 0에 수렴하여 분모가 0이 되는 현상 방지:
  - diffY >= 0: 완전 수직 상향 (+89.9도) 직상 사격.
  - diffY < 0: 완전 수직 하향 (-89.9도) 직하 사격 (성벽/절벽 바로 아래 타격).
- **일반 거리 (R >= 0.2m)**:
  - 포물선 궤적 방정식의 근의 공식:
    `tan(theta) = (v0^2 ± sqrt(v0^4 - g * (g * R^2 + 2 * diffY * v0^2))) / (g * R)`
    - **저각 해 (Low Arc) `-` 부호**: 직사(Flat) 모드 및 사선 트인 일반 사격에 적용. 얕고 빠른 직사 궤적.
    - **고각 해 (High Arc) `+` 부호**: 아군/언덕 차폐 시 머리 위를 넘기는 포물선 궤적.
  - **각도 범위 전방위 개방**: `-89.5도 ~ +89.5도` 완전 허용으로 언덕 아래 내리꽂는 하향 직사부터 절벽 위 상향 직사까지 전 영역 지원.

### 2. 인체 역학적(Biomechanical) 무기 발사 위치 실시간 연산
- 사수가 조준하는 앙각(Pitch)에 따라 어깨 관절을 피벗으로 팔을 뻗는 손끝 위치를 삼각함수로 실시간 계산:
  - 조준 앙각: `aimPitch = atan2(targetH - shoulderH, horizD)`
  - 수직 높이: `finalLaunchY = shoulderH + sin(aimPitch) * launchOffset.z`
  - 전방 도달: `reachDist = cos(aimPitch) * launchOffset.z + (aimPitch < 0 ? 0.25 * -sin(aimPitch) : 0)` (성벽 턱 내밀기 보정)
  - 최종 발사 원점: `muzzlePos = unitPos + (up * finalLaunchY) + (forward * reachDist) + (right * launchOffset.x)`
  - **시각적 체감**: 수평(1.35m) -> 상향 시 머리 위(최대 2.0m) -> 하향 시 무릎/허리(0.7m)로 손끝 위치가 진짜 사람처럼 동적 이동.

### 3. 선형 공기 저항(Linear Drag) 감속 물리 모델 & 총 체공 시간
- 공기 저항 미분방정식: `a_drag = -k * v` (k = projectileDrag)
- 실시간 속도 감속: `v(t) = v0 * exp(-k * t)`
- 수평 도달 거리 공식: `x(t) = (vHoriz / k) * (1 - exp(-k * t))`
- 정확한 총 체공 시간 T 산출:
  `T = -ln(1 - (k * R / vHoriz)) / k`  (단, k == 0일 때는 이상 포물선 T = R / vHoriz)

### 3. 포물선 궤적 엄격 준수 실시간 3D 위치 및 접선 속도 벡터 연산
- 경과 시간 t (0 <= t <= T) 기준 실시간 수평 진행률:
  `s(t) = (1 - exp(-k * t)) / (1 - exp(-k * T))`
- 실시간 수평 거리 및 위치:
  `x(t) = R * s(t)`
  `pos_xz(t) = startPos + horizontalDir * x(t)`
- 실시간 수직 높이 (포물선 궤적 방정식):
  `y(x) = startPos.y + x * tan(theta) - (g * x^2) / (2 * v0^2 * cos^2(theta))`
- 실시간 접선 속도 벡터 (체공 중 회전 정렬):
  - 실시간 수평 속력: `vx(t) = (R * k * exp(-k * t)) / (1 - exp(-k * T))`
  - 실시간 수직 속력: `vy(t) = (tan(theta) - (g * x) / (v0^2 * cos^2(theta))) * vx(t)`
  - `velocity(t) = horizontalDir * vx(t) + Vector3.up * vy(t)`
  - 화살 회전: `Quaternion.LookRotation(velocity)` (화살촉이 궤적 접선에 오차 없이 일치)
- **감속 체감**:
  - 발사 순간에는 `v0`(30m/s)로 시원하게 출발.
  - 비행하는 동안 공기 저항으로 속도가 지속 감소하여, 정점을 지나 목표 지점으로 떨어질 때 묵직하고 실감나게 착탄.

### 4. 일제사격 화살 다발(Volley Bundle) 및 행별 미세 분산
- 모든 병사가 부대 공통 기준 탄도각을 공유하여 하나의 웅장한 화살 다발을 형성.
- 사수의 행 인덱스(`shooterRow`)에 따라 행당 약 +0.7도의 미세 상향 분산(Rank Offset)을 가산하여 화살들이 앞열 머리 위를 스치며 자연스러운 다발을 형성.
- 전방 적이 아군과 백병전 중이거나 언덕 너머 사격 시 부대 전체가 자동으로 고각 해를 채택.

### 5. 3축 공간 및 사선 클리어런스 판정 공식
1. **후방 검사**: 최후열(`Row >= totalRows - 1`)이거나 견착 무기(`minRearSpacing == 0`), 또는 부대 세로 간격(`squadSpacingZ >= minRearSpacing`) 시 통과.
2. **측면 검사**: 부대 가로 간격(`squadSpacingX >= minLateralSpacing`) 시 통과.
3. **전방 사선 및 언덕 경사면 검사**:
   - 1열: 무조건 통과.
   - 체커보드 2열: 틈새 직사 허용 시 통과.
   - 3열 이상 또는 직렬 2열:
     - 앞열 간격: `distToFront = Row * max(0.5, squadSpacingZ)`
     - 언덕 지면 고도 우위: `slopeDy = (shooter.y - enemy.y) * (distToFront / distToEnemy)`
     - 탄도 앙각 고도: `elevationDy = distToFront * tan(baseAngle)`
     - 총 여유고: `totalClearance = slopeDy + elevationDy`
     - 판정: `totalClearance >= headClearanceMargin` 충족 시 사격 허용!
