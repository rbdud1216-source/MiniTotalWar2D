## 💡 1. 기획 배경 및 문제 정의 (Background & Problem)

### 1.1 현재 시스템의 동작 및 한계점
1. **평지 사격 시의 타당성**:
   - 평지에서는 사수와 적이 같은 높이에 있으므로, 물리적으로 적의 1열(앞열) 병사가 뒷열 병사를 가로막습니다.
   - 따라서 직사 화기(총/쇠뇌)가 적의 앞열부터 깎아먹는 것은 현실적이며 자연스럽습니다.
2. **고지대(언덕 위) 사격 시의 부자연스러움 (핵심 문제)**:
   - 아군 사수가 언덕 능선이나 성벽 등 **적보다 고도가 높은 고지대에서 내려다보며 사격(Plunging Fire, 부각 사격)**할 때도 모든 총알이 오직 **적의 맨 앞줄(1열)에만 집중적으로 몰려서 꽂히는 현상**이 발생합니다.
   - 사수가 위에 있다면 적 부대의 1열뿐만 아니라 2열, 3열, 4열, 5열 등 방진의 깊숙한 종심(Depth) 전체가 훤히 내려다보이므로, **적 부대 전체에 걸쳐 골고루 총알이 쏟아져야 현실적이고 웅장한 전술 연출**이 완성됩니다.

```
[현재 문제 상황 (평지/고지대 공통 앞열 쏠림)]
(언덕 위 사수)
     ● \
         \
          \ (앞열 1명에게만 90% 쏠림!)
           ▼
         [1열] [2열] [3열] [4열] (적 방진)
          (피격) (안전) (안전) (안전)

[개선 목표: 고지대 하향 직사 화망 분산 (Plunging Fire)]
(언덕 위 사수)
     ● \   \     \       \
        \   \     \       \
         ▼   ▼     ▼       ▼
        [1열] [2열] [3열] [4열] (적 부대 전체에 골고루 탄막 투하!)
```

## 🎯 2. 핵심 목표 (Design Objectives)

1. **고저차(Elevation Advantage) 기반 조준 모드 자동 전환**:
   - 사수와 목표 적 사이의 수직 고저차(`deltaY`) 및 사격 부각(Depression Angle)을 실시간 감지하여, 고지대 우위가 확보되면 **'종심 균등 분산 사격(Plunging Volley)'** 모드로 자동 전환.
2. **적 부대 종심(Rank/Row) 관통 사선 및 저수지 샘플링**:
   - 앞열만 락온하던 최단거리 가중치를 고지대에서는 과감히 해제하고, 시야에 들어온 적 방진의 1열부터 후열까지 전 부대원을 대상으로 **균등 확률(Equal Opportunity) 또는 열 분산 타겟팅** 적용.
3. **기하학적 앞열 두부(머리) 클리어런스 검증**:
   - 하향 탄도가 앞열 병사의 머리(1.6m 높이) 위를 실제로 통과할 수 있는 충분한 각도인지 수학적으로 검증하여, 물리적으로 타당한 뒷열 적만 유효 타겟으로 조준.
4. **듀얼 시뮬레이션 모드 100% 동일 적용**:
   - 하이브리드 GameObject 모드([UnitJobSimulationManager.cs](file:///c:/unityProject/MiniTotalWar2D/Assets/Scripts/UnitJobSimulationManager.cs))와 순수 ECS 모드([UnitCombatAndMovementSystem.cs](file:///c:/unityProject/MiniTotalWar2D/Assets/Scripts/ECS/Systems/UnitCombatAndMovementSystem.cs)) 양쪽 모두에 완벽하게 일치하는 알고리즘 탑재.

## 📐 3. 핵심 알고리즘 및 수학 공식 명세 (Algorithms & Math)

### 3.1 고도 우위 및 사격 부각(Depression Angle) 판정
사수 위치 P_shooter 와 목표 적 부대 중심 P_target 의 기하학적 관계를 측정합니다:

- **수직 고도차**:
  deltaY = P_shooter.y - P_target.y
- **수평 거리**:
  D_horiz = sqrt((P_target.x - P_shooter.x)^2 + (P_target.z - P_shooter.z)^2)
- **사격 부각 (하향 각도)**:
  theta_plunge = atan2(deltaY, D_horiz) * Mathf.Rad2Deg

#### 🎯 고지대 판정 조건 (Elevation Advantage Trigger):
다음 조건 중 하나 이상을 만족할 때 **고지대 분산 사격 모드**가 활성화됩니다:
1. 수직 고도차 deltaY >= 1.8m (사람 키 1명 이상의 높이 우위)
2. 사격 부각 theta_plunge >= 3.5도

---

### 3.2 앞열 두부(Head) 클리어런스 기하학
내려다보는 각도가 충분하지 않은데 뒷열을 조준하면 앞열 병사의 모자나 어깨에 총알이 걸리게 됩니다.  
따라서 사수가 적 k열 병사를 조준할 때, 그 앞의 1열 병사의 머리 위를 지나갈 수 있는지 검증합니다:

```
(사수 어깨: Ys)
    ● 
     \  
      \  (선분: 사수 어깨 -> K열 가슴)
       \       [1열 머리(Yhead)]
        \         |
         \--------+----------● (K열 가슴: Yk)
          \       |         /
           \      |        /
----------------------------------- (지면)
```

- **클리어런스 공식**:
  - 사수 어깨 높이: Y_s = P_shooter.y + 1.4m
  - 목표 k열 적 가슴 높이: Y_k = P_target_k.y + 1.0m
  - 앞열 장애 지점에서의 탄도 높이 Y_ray:
    t_front = (앞열까지의 수평 거리) / (목표 k열까지의 수평 거리)
    Y_ray = Y_s + (Y_k - Y_s) * t_front
  - 앞열 병사 머리 높이: Y_head = P_front.y + 1.65m
  - **사선 통과 조건**:
    Y_ray >= Y_head + 0.10m (여유 마진 10cm)

-> **결론**: 고지대 각도가 충분하면 1열 머리 위로 탄도가 여유롭게 지나가므로 뒷열(2~6열) 타격이 물리적으로 100% 가능해집니다!

### 3.3 타겟 스코어링 공식 개선 (Target Scoring)

#### [기존 평지 공식]:
```csharp
// 거리(sqrDist)가 가장 가까운 1열 적이 무조건 최소 비용을 얻어 독점
float cost = sqrDist + (lateralSqr * 2.5f);
```

#### [고지대 직사 개선 공식 (Plunging Scoring)]:
고도 우위가 확보되면 거리 페널티(`sqrDist`)를 대폭 상쇄하고, **정면 축 정렬(Lateral Alignment)과 무작위 난수 시드(Random Dispersion)**를 결합합니다:

```csharp
if (isPlungingFire)
{
    // 🎯 고지대 사격: 거리 제곱 페널티를 90% 감쇄하고, 정면 시선 내에 있는 적이라면
    // 1열부터 후열까지 전 병사에게 균등한 조준 기회 부여!
    float depthFactor = 0.05f; // 거리(종심)에 따른 차등을 거의 없앰
    float randomJitter = (seed % 100) * 0.5f; // 사수마다 고유 분산 시드 부여
    
    cost = (fwdDist * depthFactor) + (lateralSqr * 3.0f) + randomJitter;
}
else
{
    // 평지 사격: 기존대로 가장 가까운 1열 적 우선 락온
    cost = sqrDist + (lateralSqr * 2.5f);
}
```

## 🏗️ 4. 시스템별 상세 수정 설계 (Implementation Blueprint)

### 4.1 `UnitJobSimulationManager.cs` (GameObject 모드 C# Job)
1. **`UnitJobData` 구조체에 고도 우위 플래그 연동**:
   - 사수와 목표 부대 간의 고저차를 사전 계산하거나, Job 내부에서 `myPos.y - enemyPos.y` 계산.
2. **`FindTargetJob` 내 분산 타겟팅 로직 개편**:
   - `me.trajectoryMode == 1` (직사 유닛)일 때:
     - 평지: 기존대로 사선이 확보된 가장 가까운 적 우선(`bestVisibleIdx`).
     - **고지대 (`myPos.y - targetSquadCenter.y >= 1.8f`)**:
       - 사선(LoS)이 뚫린 적 부대원들 중 저수지 샘플링(Reservoir Sampling) 후보군 풀을 1열뿐만 아니라 **전체 열로 전면 개방**.
       - 각 사수의 고유 인덱스(`seed = index * 7919 + col * 31`)를 이용해 목표 부대 내 살아있는 적들을 1열, 2열, 3열, 4열 골고루 분산 선택!

### 4.2 `UnitCombatAndMovementSystem.cs` (Pure ECS 모드)
1. **`Frontal Alignment Scoring` 블록 수정 (라인 260~290)**:
   - `combat.IsRangedUnit == 1 && combat.TrajectoryMode == 1`일 때 고도차 `float dy = currentPos.y - other.Position.y;` 계산.
   - `dy >= 1.8f`인 경우, `sqrDist`에 곱해지는 가중치를 `0.05f`로 축소하고 정면 횡방향 정렬(`lateralSqr`) 위주로 매칭하여, **내 정면 열에 마주보고 서 있는 적 방진의 깊숙한 뒷열까지 자연스럽게 조준선이 관통**하도록 처리.

### 4.3 `Squad.cs` & `ArrowSimulationManager.cs` (탄도 연동)
1. **`Squad.cs` 전술 이동 연동**:
   - 고지대에 위치한 직사 부대는 전열뿐만 아니라 적 방진 전체를 조준하므로, 부대 전체의 사격 개시 선이 적 방진 전역을 포괄하도록 일제사격 태세 동기화.
2. **`ArrowSimulationManager.cs` 하향 각도 속도 보존**:
   - 언덕 위에서 아래로 쏠 때 중력 가속도와 하향 앙각이 더해져 더욱 빠르고 매섭게 내리꽂히도록 속도 벡터 일치화.
