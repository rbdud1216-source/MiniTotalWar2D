## 💡 1. 기획 배경 및 핵심 개념 정립

### 1.1. 사용자 요구사항
> *"유닛의 생명력(지금 체력으로 표기된 것) 과 체력(지친 정도)로 나눠야 함. 유닛을 이동시키거나 근접교전 시키면 점점 지쳐야 함. 그외 토탈워에 있는 수치가 있나?"*

### 1.2. 핵심 개념 분리: 생명력 vs 체력
기존 게임들이 흔히 혼용하던 개념을 토탈워 정통 규격에 맞춰 명확하게 이원화합니다:
1. **❤️ 생명력 (Health / HP)**:
   - 병사의 물리적 피격 수명 (0이 되면 전사).
   - 부대의 경우: `생존 병력 수 (Alive Count)` 및 `총 생명력 합계 (Total HP)`.
2. **⚡ 체력 및 피로도 (Stamina / Fatigue / Vigor)**:
   - 행동(구보 질주, 오르막길 이동, 백병전 격투, 화살 사격)에 따라 소모되고, 제자리에 멈춰 서서 쉬면(Rest) 서서히 회복되는 기운/활력.
   - 체력이 고갈(탈진)될수록 이동속도, 공격력, 방어력, 돌격보너스가 대폭 깎이며 사기가 급락함.

### 2.0. 적 부대 상호작용 및 피아 식별 (Friend or Foe Inspection)
1. **적 부대 터치(조사 및 마우스 호버)**:
   - **마우스 호버(Hover)**: 마우스 커서를 발각된 적 부대/유닛 위에 올리면 즉시 적 정보창 프리뷰 표출.
   - **좌클릭 조사(Inspect)**: 적 부대를 좌클릭하면 적 정보창이 우측 상단에 고정되어 지속 표출.
   - **전장의 안개(Fog of War) 연동**: 시야에 발각된 적(`isSpotted == true`)만 정보창 표출이 허용됨.
2. **시각 테마 분기**:
   - **아군 (Friend)**: 칠흑 수묵 차콜 배경(`RGBA(0.08, 0.09, 0.11, 0.94)`) + 앤틱 골드 테두리 + `🛡️ [아군]`
   - **적군 (Enemy)**: 흑홍빛 수묵 먹물 배경(`RGBA(0.14, 0.05, 0.05, 0.95)`) + 진홍 루비 골드 테두리 + `⚔️ [적군]`

### 2.1. 세부 UI 블록 구성
1. **헤더 영역 (Header)**: 부대 명칭, 병종 뱃지, 누적 킬 수 (Kill Count).
2. **생명력 바 (Health Bar)**: 생존 인원 수(`58/60`) 및 체력 비율에 따른 색상 보간 (녹색 → 황색 → 적색).
3. **사기 게이지 (Morale Bar)**: 실시간 사기 수치(`78/100`) 및 4단계 심리 상태.
4. **체력/활력 게이지 (Fatigue Bar)**: 실시간 피로도 잔여량 및 6단계 활력 상태 (신선함 → 탈진).
5. **전투 스탯 격자 (Combat Stats Grid)**:
   - 근접 공격력 / 장갑 관통 피해 (AP Damage)
   - 장갑/방어력 (Armor Rating) & 근접 방어 (Melee Defense)
   - 돌격 보너스 (Charge Bonus) & 물리 질량 (Mass)
   - 원거리 사격 공격력, 유효 사거리, 잔여 탄약 수치
6. **현재 태세 및 상태 푸터 (Footer)**:
   - 현재 행동(대기, 행진, 돌격, 난전, 사격 중) 및 전술 대형(일자진, 방진, 산개진 등).

## ⚡ 3. 체력 및 피로도(Fatigue / Stamina) 시스템

### 3.1. 피로도 6단계 활력 체계 (Vigor Stages)

| 단계 (Stage) | 피로도 잔여율 | 전투 스탯 페널티 및 심리 영향 | 시각 색상 |
| :--- | :--- | :--- | :--- |
| **1. 신선함 (Fresh)** | 85% ~ 100% | 페널티 일절 없음 (최대 전투력 발휘) | 밝은 청록색 |
| **2. 활기참 (Active)** | 70% ~ 84% | 페널티 없음 (가벼운 보행 및 대기 상태) | 녹색 |
| **3. 약간 지침 (Winded)** | 50% ~ 69% | 이동속도 -5%, 돌격보너스 -10%, 재장전시간 +5% | 연두색 |
| **4. 지침 (Tired)** | 30% ~ 49% | 이동속도 -15%, 돌격 -20%, 근접공격 -10%, 근접방어 -10%, **사기 -4** | 황색 |
| **5. 매우 지침 (Very Tired)** | 15% ~ 29% | 이동속도 -25%, 근접공격 -20%, 근접방어 -20%, 돌격 -35%, **사기 -8** | 주황색 |
| **6. 탈진 (Exhausted)** | 0% ~ 14% | 이동속도 -35%, 근접공격 -30%, 근접방어 -30%, 돌격 -50%, 장전 +35%, **사기 -15** | 짙은 적색 |

### 3.2. 행동별 피로도 소모 및 회복 수치 (Stamina Delta)
- **제식 보행 (Walk)**: 피로도 소모 0 (평지 보행 시 초당 +0.2% 미세 회복)
- **구보/달리기 (Run)**: 초당 **-0.8%** 소모
- **오르막길 달리기 (Uphill Run)**: 지형 경사도 비례 초당 **-1.6% ~ -2.5%** 급격 소모
- **백병전 난전 (Melee Combat)**: 초당 **-1.5%** 소모
- **원거리 사격 및 장전 (Shoot & Reload)**: 1발 사격 시 **-1.0%** 즉시 소모
- **제자리 대기 및 휴식 (Idle / Rest)**: 초당 **+1.2%** 빠른 회복 (교전 이탈 후 40~50초 휴식 시 완전 회복)

## 🧠 4. 사기(Morale / Leadership) 시스템 아키텍처

### 4.1. 사기 4단계 상태 전이 (Morale States)
- **안정 (Firm, 60~100)**: 정상 지휘 통제 가능.
- **동요 (Shaken, 35~59)**: 경고 상태. 사기 바가 노란색으로 변하며 추가 충격 시 붕괴 위험.
- **붕괴 직전 (Wavering, 15~34)**: 사기 바가 주황색으로 깜빡임. 적의 1회 충격으로 즉시 패주 가능.
- **패주 (Broken, 0~14)**: 제어 불능 상태. 무기를 버리고 후방으로 도주 (일정 거리 도주 후 재집결 가능).
- **궤멸 (Shattered, 패주 중 재타격)**: 영구 전장 이탈 (재집결 불가).

### 4.2. 실시간 사기 증감 결정 요인 (Morale Modifiers)
- **기본 사기 (Base Morale)**: 병종 등급에 따라 +60 ~ +85 부여
- **사상자 누적 (Casualties)**: 20% 손실(-5), 40% 손실(-15), 60% 손실(-30)
- **단시간 대량 손실 충격 (Shock Loss)**: 4초 내 15% 이상 전사 시 -15 (10초 지속)
- **측면 피습 (Flank Attack)**: -12
- **후방 기습 (Rear Attack)**: -25
- **기병 돌격 충격 (Cavalry Charge)**: -20 ~ -40 (일시적 패닉)
- **탈진 상태 (Exhausted)**: -15
- **아군 패주 목격**: -10
- **승세 장악 / 적 패주**: +8
- **지휘관 인접 아우라**: +10

## 📊 5. 토탈워(Total War) 정통 핵심 전투 수치(Stats) 총람표

사용자 질문: *"그외 토탈워에 있는 수치가 있나?"*  
토탈워 엔진의 실제 핵심 전투 스탯 및 상태 수치들을 체계적으로 분류한 표준 명세입니다:

| 대분류 | 세부 수치 명칭 (Total War Stat) | 역할 및 실제 전술 효과 |
| :--- | :--- | :--- |
| **생존 & 활력** | **생명력 (Health / HP)** | 개별 병사의 생명력 및 부대 전체 잔여 생명력 합계 |
| | **체력 / 피로도 (Fatigue / Vigor)** | 6단계 활력. 달리기/교전 시 소모, 이동속도/공격력/사기 직결 |
| | **사기 / 통솔력 (Morale / Leadership)** | 부대의 항전 의지. 0 추락 시 패주하여 전장 이탈 |
| **방어 스탯** | **장갑 / 방어력 (Armor Rating)** | 일반 공격 피해 감쇄율 (0 ~ 10,000 / 0 ~ 100%) |
| | **근접 방어 (Melee Defense)** | 적의 근접 타격을 회피하거나 방패로 쳐낼 확률 (명중률 상쇄) |
| | **방패 방호율 (Shield Block Chance)** | 전방 120도에서 날아오는 원거리 화살을 100% 무효화할 확률 (35%~55%) |
| | **돌격 방어 (Charge Defense)** | 방진 대기(Bracing) 시 적 기병 돌격 보너스 무효화 및 적에게 피해 반사 |
| **근접 공격** | **근접 공격력 (Melee Attack)** | 적의 근접 방어를 뚫고 타격에 성공할 기본 명중 확률 |
| | **기본 무기 피해 (Base Damage)** | 적의 장갑/방어력에 의해 감쇄되는 일반 물리 피해 |
| | **장갑 관통 피해 (Armor-Piercing, AP)** | **적 방어력을 100% 무시하고 직격하는 순수 고정 피해 (중장갑 킬러)** |
| | **대형 적 보너스 (Bonus vs Large)** | 기병/괴수 상대 시 공격력 및 피해량 대폭 가산 (창병 특화) |
| | **보병 상대 보너스 (Bonus vs Infantry)** | 보병 밀집 방진 상대 시 공격력 및 피해량 가산 (대검병 특화) |
| | **돌격 보너스 (Charge Bonus)** | 돌격 충돌 후 첫 10~15초간 공격력과 명중률이 폭발적으로 급증 |
| **물리 & 이동** | **질량 / 무게 (Mass / Weight)** | 유닛 무게 (보병 100, 기병 600, 전차 1200). 충돌 넉백 및 돌파력 결정 |
| | **이동 속도 (Movement Speed)** | 보행(Walk, 1.2m/s) 및 구보(Run, 2.8m/s) 기본 속도 |
| **원거리 사격** | **유효 사거리 (Range)** | 최대 타격 가능 거리 (궁병 140m, 총병 90m, 투창 45m) |
| | **사격 피해 & 관통 피해 (Missile & AP)** | 탄환/화살 1발당 일반 피해 및 장갑 관통 피해 |
| | **탄약량 (Ammunition)** | 1인당 휴대 탄약 수 (0발 소진 시 백병전 모드 강제 전환) |
| | **재장전 시간 (Reload Time)** | 1발 발사 후 다음 사격까지의 쿨다운 (궁병 7초, 총병 15초) |
| | **사격 호 각도 (Firing Arc)** | 사격 가능한 정면 수평 각도 (마상궁술 360도, 총병 60도) |
| **심리 & 특성** | **공포 유발 (Causes Fear)** | 교전 중인 적 부대에게 즉시 사기 -8 감산 |
| | **섬뜩함 유발 (Causes Terror)** | 사기가 꺾인(Wavering) 적 부대와 접촉 시 즉각 패주(Broken) 발동 |
| | **은신 / 잠복 (Stalk / Hidden)** | 숲이나 지형 굴곡 속에 숨어 적 시야에서 완벽히 은폐 |
| | **완벽한 활력 (Perfect Vigour)** | 체력(피로도)이 전혀 소모되지 않고 항상 '신선함' 유지 |

## 🗂️ 6. 데이터 구조체 및 컴포넌트 설계

### 6.1. 정보창 표시용 데이터 모델 (`SquadDetailSnapshot`)
```csharp
public struct SquadDetailSnapshot
{
    public int SquadId;
    public string Name;
    public UnitType UnitType;
    public bool IsPlayer;
    public bool IsRanged;
    
    // 1. 생명력 (Health) & 병력 수
    public int CurrentAliveCount;
    public int MaxAliveCount;
    public float CurrentHpSum;
    public float MaxHpSum;
    public float HealthRatio => (MaxHpSum > 0) ? (CurrentHpSum / MaxHpSum) : 0f;
    
    // 2. 체력 및 피로도 (Stamina / Fatigue)
    public float CurrentStamina;      // 0 ~ 100
    public float MaxStamina;          // 기본 100
    public FatigueStage FatigueStage; // Fresh, Active, Winded, Tired, VeryTired, Exhausted
    public float StaminaRatio => (MaxStamina > 0) ? (CurrentStamina / MaxStamina) : 0f;
    
    // 3. 사기 (Morale / Leadership)
    public float CurrentMorale;       // 0 ~ 100
    public float MaxMorale;           // 기본 100
    public MoraleState MoraleState;   // Firm, Shaken, Wavering, Broken, Shattered
    public string MoraleTooltip;
    
    // 4. 전투 능력치
    public float BaseDamage;
    public float ArmorPiercingDamage;
    public float ArmorRatingPercent;
    public float ArmorTightnessBonusPercent;
    public float MeleeDefense;
    public float ChargeBonus;
    public float Mass;
    public float MoveSpeed;
    
    // 5. 원거리 전용 스탯
    public float RangedDamage;
    public float RangedApDamage;
    public float RangedRange;
    public int CurrentAmmo;
    public int MaxAmmo;
    public float ReloadTime;
    
    // 6. 전술 태세 & 통계
    public UnitCommandState CurrentState;
    public SquadFormationType FormationType;
    public int TotalKills;
}
```

## 📅 7. 3단계 구현 로드맵

- **[1단계] UI 패널 프레임워크 및 생명력/체력 듀얼 게이지 연동 (우선 구현)**
  - 화면 좌하단 `UnitDetailInfoPanel` 생성 (단일 부대/유닛 선택 시 자동 팝업).
  - 부대 이름, 병종, 생명력 바(Health), 체력 바(Stamina), 킬수, 기본 공격/방어/속도 스탯 표시.
- **[2단계] 체력(피로도) 소모/회복 엔진 및 스탯 페널티 연동**
  - 달리기, 오르막길, 백병전 난전 시 피로도 실시간 소모 및 제자리 휴식 회복 로직 구현.
  - 지침/탈진 상태에 따른 이동속도, 공격력, 방어력 실시간 감쇄 연동.
- **[3단계] 사기(Morale) 엔진 및 패주/재집결 AI 연동**
  - 측후방 피습, 사상자 충격, 탈진 페널티에 따른 사기 감산 및 패주(Routing) 도주 구현.
