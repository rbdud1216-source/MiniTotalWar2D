# 🏹 토탈워 스타일 원거리 사격 호(Firing Arc), 3D 포물선 탄도 궤적 및 지형 차폐 시각화 기획서
(Total War Style Firing Arc, Ballistic Trajectory & Terrain Obstruction Visualization System Specification)

---

## 💡 1. 핵심 요약 및 기획 배경 (Summary & Background)

### 1.1 기획 배경
- **문제점**:
  - 현재 원거리 부대(궁병, 총병) 및 원거리 자유 유닛은 사거리 정보가 화면에 표시되지 않아, 플레이어가 유닛을 어느 위치까지 전진시켜야 사격이 개시되는지 직관적으로 판단하기 어렵습니다.
  - 원거리 부대를 선택하고 적 부대에 마우스를 올렸을 때(Target Hovering), **"부대가 어디에 멈춰 서서 쏘는지", "화살/총알이 어떤 궤적으로 날아가는지", "중간 언덕에 막혀서 쏠 수 없는지"**에 대한 시각 피드백이 전무하여 답답함이 유발됩니다.
- **핵심 목표**:
  1. **토탈워(Total War) 사격 부채꼴(Firing Arc)**: 부대 선택 시 부대 정면 기준 사격 가능 각도(총병 60°, 궁병 120°)와 최대/최소 사거리를 지형 표면에 완벽 밀착(Terrain-Conforming) 시각화.
  2. **목표 호버링 시 정지 사격 위치 프리뷰 (Stand-and-Fire Position)**: 적 부대에 마우스를 올리면, 부대가 사격을 위해 어디까지 이동하여 멈춰 설지 예상 도착 지점을 고스트 마커로 안내.
  3. **3D 물리 기반 포물선 탄도 궤적 곡선 (Ballistic Trajectory Arc)**: 사격 위치에서 적 부대까지 곡사(활) 및 직사(총) 투사체가 날아가는 실제 물리 궤적을 3D 라인으로 시각화.
  4. **지형 차폐 및 사격 불가 실시간 경고 (Terrain Obstruction & Blocked LoS)**: 탄도 궤적이 중간 언덕이나 능선에 가로막힐 경우, **궤적 색상을 경고 빨간색으로 즉시 전환**하고 **충돌 지점에 차폐 마커(Blocked Point)**를 띄워 사격 불가 사유를 100% 직관적으로 전달.
  5. **자유 유닛(Free Unit) 단독 선택 제어**: 다수 선택 시 화면 공해를 방지하고, **오직 1마리를 개별 선택했을 때에만** 발밑에서 사거리가 표시되도록 정밀 제어.

## 🎮 2. 토탈워(Total War) 원거리 전술 시각화 레퍼런스 및 UX 명세

### 2.1 토탈워 3대 원거리 시각 시스템 구성 요소

```
[원거리 시각 시스템 3대 기둥]
 ├── 1. 평상시 부대 선택 (Selection) ────> 지형 밀착 부채꼴 사격 호 (Firing Arc)
 ├── 2. 마우스 드래그 배치 (Drag Preview) ─> 예상 배치 좌표 기준 선행 사격 호 투영
 └── 3. 적 부대 마우스 오버 (Target Hover) ──┬─> 예상 정지 사격 위치 마커 (Stand Position)
                                            ├─> 3D 포물선 탄도 궤적 곡선 (Ballistic Arc)
                                            └─> 지형 차폐 시 빨간색 경고 & 충돌점 표시
```

1. **지형 표면 밀착 부채꼴 콘 (Terrain-Conforming Firing Arc)**:
   - 외곽 호(최대 사거리), 내곽 호(최소 사거리 5m), 양측 한계 각도선, 은은한 반투명 채우기(투명도 10~15%).
   - `TerrainHeightManager`의 고속 높이 샘플링을 결합하여 언덕 굴곡을 따라 자연스럽게 지표면에 찰떡 밀착.
2. **예상 정지 사격 위치 연출 (Stand-and-Fire Path & Arc - 토탈워 완벽 고증)**:
   - 별도의 인위적인 발판 오브젝트를 만들지 않고, **부대에서부터 정지 지점까지 이동 경로선(Path Line)이 이어지며, 바로 그 정지 지점에서 전방을 향해 사격 호(부채꼴)가 펼쳐지고 탄도 궤적이 연결**되는 토탈워 고증 연출을 적용합니다.
   - 현재 위치에서 이미 사거리가 닿으면 현재 부대 위치에서 즉시 탄도 궤적 출발.
3. **3D 포물선 탄도 궤적 곡선 (Ballistic Trajectory Arc)**:
   - 정지 사격 위치(또는 현재 위치)에서부터 적 부대 중심까지 이어지는 포물선 궤적 라인.
   - **곡사(활 - High Arc)**: 높은 포물선 호를 그리며 산등성이를 넘는 궤적.
   - **직사(총/쇠뇌 - Flat)**: 지면과 평행하게 날아가는 날카로운 직선 레이.
4. **지형 차폐 및 충돌 실시간 판정 (Terrain Collision Warning)**:
   - **사선 트임 (Clear)**: **에메랄드 그린 (`#2ED573`)** 유려한 발광 궤적선 (사격 가능).
   - **지형 차폐 (Blocked by Terrain)**: 
     - 궤적선이 **크림슨 레드 (`#FF2222`)**로 즉시 전환.
     - 탄도가 언덕 흙둔덕과 부딪히는 정확한 교차점에 **빨간색 경고 X 충돌 마커(Blocked Collision Point)** 생성.
     - 마우스 커서가 사격 불가(Obstructed LoS) 아이콘으로 전환되어 플레이어가 "왜 사격 명령을 내려도 쏘지 못하는지" 즉시 납득.
5. **다중 부대 선택 시 개별 100% 동시 표출 (Total War Original)**:
   - 선택된 모든 원거리 부대가 각자의 위치와 회전각을 기준으로 사격 호와 (호버링 시) 탄도 궤적을 100% 각각 지면에 모두 표시.

## 🛠️ 6. 핵심 알고리즘, 물리/전투 수학 공식 & 조작법

### 6.1 물리 기반 3D 포물선 탄도 궤적 산출 수학 (Ballistic Math)
게임 내 투사체 시뮬레이터(ArrowSimulationManager.cs)와 100% 동일한 인게임 물리 파라미터를 사용하여 오차 없는 궤적을 그립니다:

1. **목표물 수직 고저차 및 수평 거리**:
   - D_xz = Target.xz - Shooter.xz, d_xz = length(D_xz)
   - dy = Target.y - Shooter.y
2. **발사 앙각 (aimPitch) 산출**:
   - **곡사 (HighArc: 활)**:
     - 중력 가속도 g = 9.8 * GravityScale
     - 투사체 속도 v0 = 42m/s
     - 고각 탄도 방정식: theta = 0.5 * arcsin((g * d_xz) / (v0 * v0)) (고각 채택 시 90도 - theta)
   - **직사 (Flat: 총)**:
     - theta = arctan(dy / d_xz) (직선 조준각)
3. **매개변수 t (0.0 -> 1.0)에 따른 궤적 위치 P(t) 산출**:
   - X(t) = Shooter.x + D_xz.x * t
   - Z(t) = Shooter.z + D_xz.z * t
   - Y(t) = Shooter.y + dy * t + 4 * Harc * t * (1 - t)
     - 여기서 Harc는 탄도 앙각에 따른 포물선 정점 최고 높이.

### 6.2 실시간 지형 차폐 및 충돌 검출 알고리즘 (Terrain Collision Sampling)
- 탄도 궤적을 K=30개의 세그먼트로 나눕니다 (tk = k / 30).
- 각 세그먼트 위치 P(tk)에서 지형 높이를 샘플링합니다:
  - Y_terrain = TerrainHeightManager.SampleHeightFast(P(tk).x, P(tk).z)
- **충돌 조건**:
  - Y(tk) <= Y_terrain + 0.10m (지표면 10cm 이내 접근 시 지형 충돌로 판정)
- **차폐 처리**:
  - 첫 번째 충돌 지점 P(t_hit)를 기록.
  - 궤적 전체를 크림슨 레드(#FF2222)로 변경하고, P(t_hit) 지점에 지형 차폐 경고 링/X 마커를 렌더링.

### 6.3 정지 사격 위치(Stand Position) 산출 알고리즘
- 만약 현재 부대 위치가 적 부대와 사거리 밖이거나(dist > maxRange * 0.85f), 언덕에 막혀 사선이 없다면:
- 적 중심을 향하는 방향 벡터 u_dir을 기준으로 사선이 확보되는 능선 마루 또는 최적 사거리(사거리의 70% 지점)를 스텝 탐색:
  - P_stand = EnemyCenter - u_dir * (maxRange * 0.70f)
  - P_stand.y = TerrainHeightManager.SampleHeightFast(P_stand.x, P_stand.z)
- 이 P_stand 위치에 **반투명 부대 발판 고스트 마커**를 표출하여 플레이어에게 "부대가 여기까지 이동한 뒤 멈춰서 쏜다"는 것을 시각적으로 사전 고지.

## 🖱️ 7. 사용자 조작 및 상호작용 규칙 (Interaction Rules)

### 7.1 조작 상태별 시각 반응 일람표

| 사용자 액션 | 시각적 표시 반응 |
| :--- | :--- |
| **원거리 부대 좌클릭 선택** | 부대 발밑에 **부채꼴 사격 호(Firing Arc)** 표시. |
| **빈 땅 마우스 호버** | 사격 호만 유지, 탄도 궤적선은 표시되지 않음. |
| **적 부대 마우스 오버 (Hovering)** | **3D 포물선 탄도 궤적선** + **정지 사격 위치 고스트 마커** 즉시 출현.<br>• 사선 확보 시: **에메랄드 그린 (#2ED573)**<br>• 언덕 차폐 시: **크림슨 레드 (#FF2222) + 지형 충돌 X 마커** |

| **마우스 우클릭 드래그 배치** | 예상 배치 위치 및 회전각 기준으로 **선행 사격 호 프리뷰** 투영. |
| **자유 유닛 1마리 좌클릭 선택** | 해당 1마리 발밑에만 개별 사거리 원/부채꼴 표시. |
| **자유 유닛 2마리 이상 드래그 선택** | 시각 공해 방지를 위해 **모든 사거리 표시 완전 자동 숨김**. |
