# 🌐 근현대 대규모 전선·사단급 자율 자동전투 및 전략지도 스트리밍 종합 기술 기획서

본 기획서는 플레이어의 인지 지휘 한계(여단급)를 넘어선 **사단급(Division) 대규모 근현대 총력전 전선(Frontline)**을 구현하기 위해, **1) 화면 밖 통계적 교환비 시뮬레이션(란체스터 법칙)**, **2) 부관 교리 AI 기반 자율 자동전투**, **3) 부대당 30바이트 초경량 데이터 구조(사단 전체 3KB)**, **4) 전략지도 ⇄ 전술 전장 ⇄ 카메라 줌인 3단계 심리스 스트리밍**, **5) 포격·참호·화재 잿더미 흔적의 데이터 기반 영구 보존**을 정의한 프로젝트 영구 보존용 완전체 기술 자산 명세서입니다.

## 💡 1. 핵심 요약 & 시스템 목표 (Summary & Objective)

근현대 전쟁은 고대·중세의 국소적 단기 회전(Pitch Battle)과 달리, **수십~수백 km에 걸쳐 끝없이 이어진 전선(Frontline)에서 24시간 쉬지 않고 총포성이 울리는 지속형 총력전**입니다.
인간 플레이어가 직접 정밀하게 미세 조작(Micro-control)할 수 있는 부대 규모는 최대 **여단급(10~20개 부대)**에 불과하므로, 사단급 이상의 거대 전선을 표현하기 위해서는 **"화면 안의 정밀 물리 전투"**와 **"화면 밖의 가상 통계 전투(AI 자율 교전)"**가 완벽하게 맞물리는 이원화 아키텍처가 필수적입니다.

```
+---------------------------------------------------------------------------------------------------+

+---------------------------------------------------------------------------------------------------+
|  [1단계: 거대 전략 지도 (Campaign Strategic Frontline Map)]                                       |
```

## ⚙️ 3. 핵심 데이터 구조체 명세 (Data Structures)

### 3.1 30바이트 초경량 부대 데이터 구조체 (`FrontlineSquadData`)
```csharp
[System.Serializable]
public struct FrontlineSquadData
{
    public float posX;              // 4 Bytes: 월드 X 좌표
    public float posZ;              // 4 Bytes: 월드 Z 좌표
    public float rotationY;         // 4 Bytes: 부대 정면 방위각 (0~360도)
    public byte factionId;          // 1 Byte: 진영 (0: 아군, 1: 적군, 2: 동맹)
    public byte unitType;           // 1 Byte: 병종 (1: 소총수, 2: 기관총, 3: 박격포, 4: 야포, 5: 전차)
    public ushort currentSoldiers;  // 2 Bytes: 현재 생존 인원 (0~65,535)
    public ushort maxSoldiers;      // 2 Bytes: 편제 최대 인원
    public byte combatOrder;        // 1 Byte: 부관 AI 명령 (0: 대기, 1: 전진, 2: 참호사수, 3: 포격, 4: 후퇴)
    public ushort ammoCount;        // 2 Bytes: 잔여 탄약량
    public byte morale;             // 1 Byte: 현재 사기 (0~100)
    public byte suppressionLevel;   // 1 Byte: 제압도 (0~100, 높을수록 이동 불가 및 명중률 급감)
    public ushort targetSquadIndex; // 2 Bytes: 현재 교전 중인 목표 부대 인덱스
    // 총합: 24 Bytes (패딩 포함 최대 28~32 Bytes)
}
```

```csharp
public enum FoliageState : byte
{
    Healthy = 0,    // 정상 자연 잔디
    Trampled = 1,   // 보병/전차 통행으로 짓밟혀 누움 (이동속도 0.9x 복구)
```

## 🛠️ 4. 핵심 알고리즘 및 수학 공식 (Algorithms & Math)

### 4.1 화면 밖 란체스터 전투 교환비 공식 (Lanchester's Power Law)
화면 밖 전선에서 매 초(`DeltaTime = 1.0s`) 실행되는 통계적 사상자 산출 공식:

```
1. 실효 전투력 산출:
   AttackerPower = SquadCount_A * Firepower_A * AmmoFactor_A * MoraleFactor_A
   DefenderPower = SquadCount_D * Firepower_D * AmmoFactor_D * MoraleFactor_D * CoverBonus

   * 참호(Trench) 엄폐 시: CoverBonus = 2.5 (피해량 60% 감소)
   * 숲/수풀(Bush) 엄폐 시: CoverBonus = 1.6 (피해량 37% 감소)
   * 도로/개활지 노출 시: CoverBonus = 0.8 (피해량 25% 가중)

2. 사상자 산출 (란체스터 2차 법칙 근사):
   Casualties_D = Clamp(Round(AttackerPower * 0.05 * Random(0.85, 1.15)), 0, CurrentSoldiers_D)
   Casualties_A = Clamp(Round(DefenderPower * 0.05 * Random(0.85, 1.15)), 0, CurrentSoldiers_A)

3. 전선 밀림(Frontline Shift):
   PowerRatio = AttackerPower / Max(1.0, DefenderPower)
   if PowerRatio > 1.3:
       FrontlineNode.Position += PushDirection * (0.5m * PowerRatio)
```

### 4.2 절차적 진형 확장 (Procedural Soldier Expansion)
카메라 줌인 시 부대 데이터(`FrontlineSquadData`)로부터 100명의 병사 위치를 즉시 산출하는 공식:

```
입력: 부대 중심 P_center, 방위각 theta, 열 수 Cols = 10, 간격 spacing = 1.5m
for i = 0 to currentSoldiers - 1:
    row = i / Cols
    col = i % Cols
    localX = (col - (Cols - 1) * 0.5) * spacing
    localZ = -(row * spacing)
    worldPos = P_center + RotateY(Vector3(localX, 0, localZ), theta)
    worldPos.y = GetTerrainHeight(worldPos.x, worldPos.z)
    SpawnOrUpdateVisualSoldier(i, worldPos)
```

## 📅 5. 단계별 개발 로드맵 (Development Roadmap)

### 📌 1단계: 데이터 기반 식생 시스템 구축 (Foliage Data & Streaming)
- 전장 풀을 씬에 정적으로 심지 않고, 터레인 스플랫맵 기반 **풀 데이터 맵(`TacticalFoliageDataMap`)** 생성.
- 유닛 좌표 기반 이동속도(0.8배) 및 피로도 실시간 연동.
- 카메라 줌인 시 반경(60~80m) 안의 풀만 실시간으로 그려주는 **GPU 인스턴싱 동적 렌더러** 구현.

### 📌 2단계: 풀 짓밟힘 및 화재/잿더미 흔적 연동 (Trample & Wildfire)
- 부대 이동 시 데이터 셀을 `Trampled`로 갱신하여 누운 풀 렌더링.
- 화염원 접촉 시 셀을 `Burning`으로 갱신 후 5초 디졸브, 전소 후 `AshDecal`로 상태 고정.

### 📌 3단계: 초경량 부대 데이터 및 절차적 진형 확장 (Squad Data Stream)
- 30바이트 부대 데이터 구조체 정립.
- 줌아웃 시 부대 아이콘만 표시하고, 줌인 시 0.0001초 만에 100명 병사를 즉석 전개하는 슬롯 엔진 완성.

### 📌 4단계: 사단급 자율 부관 AI 및 화면 밖 통계 전선 시뮬레이터 (Frontline AI)
- 플레이어가 조작하지 않는 다른 부대들을 위한 부관 교리 AI(엄폐 사격/간접 포격) 탑재.
- 화면 밖 전선에서 실시간으로 사상자와 전선 밀림을 계산하는 란체스터 통계 시뮬레이터 완성.
