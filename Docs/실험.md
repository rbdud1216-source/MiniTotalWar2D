## 🔬 2. 상세 항목별 실험 세부 내용

### 1️⃣ 유닛 자동 스폰 및 소환 제동 실험 (`BattleManager.cs`)
- **실험 방법**: 게임 실행(Play Button) 후 플레이어 10명, 적 30명이 소환되는 순간을 관찰.
- **기대 결과**: 소환 시 2D 물리 충돌로 인해 유닛이 전장 바깥으로 튕겨 나가지 않고 제자리에 부드럽게 정착.
- **실험 결과**: **`O` (성공)**
- **세부 설명**: `SafeSpawnRoutine` 코루틴에서 소환 찰나 마찰력(`linearDamping`)을 1000f로 올려 물리 튐 현상을 99.9% 억제한 뒤 0.05초 후 NavMesh 길 위로 안전하게 착지시킴.

### 2️⃣ 카메라 조작 실험 (`CameraController.cs`)
- **실험 방법**: 마우스 휠 스크롤 업/다운 및 마우스 휠 버튼(가운데 버튼)을 누르고 드래그.
- **기대 결과**: 휠 스크롤 시 화면 확대/축소가 이뤄지며 (`minSize` 2.0 ~ `maxSize` 15.0 범위), 휠 드래그 시 마우스 움직임에 맞춰 전장이 이동함.
- **실험 결과**: **`O` (성공)**
- **세부 설명**: `Mathf.Lerp`와 `orthographicSize` 감도 연산이 적용되어 멀리서 볼 때와 가까이서 볼 때 모두 부드럽게 카메라가 이동함.

### 3️⃣ 대형 위치 및 방향 프리뷰 시각화 실험 (`FormationPreviewer.cs`)
- **실험 방법**: 아군 유닛 선택 후 마우스 우클릭 상태로 화면을 드래그.
- **기대 결과**: 드래그 경로를 따라 유닛이 위치할 파란 점들(`PreviewDot`)과 진행 방향 하늘색 가이드 라인이 나타남.
- **실험 결과**: **`O` (성공)**
- **세부 설명**: 오브젝트 풀링을 적용하여 프레임 드랍 없이 점들과 선이 실시간으로 부드럽게 그려짐.

### 4️⃣ 유닛 선택 및 하이브리드 지휘 실험 (`PlayerController.cs`)
- **실험 방법**: 
  1. 마우스 좌클릭으로 단일 유닛 클릭
  2. 마우스 좌클릭 드래그로 녹색 박스를 만들어 여러 유닛 선택
- **기대 결과**: 선택된 아군 유닛은 청록색(`Color.cyan`)으로 색상이 변하며, 부대 소속 유닛을 클릭하면 부대원 전체가 일괄 선택됨.
- **실험 결과**: **`O` (성공)**
- **세부 설명**: 부대 유닛과 자유 유닛을 구별하여 스타크래프트 방식과 토탈워 방식을 조합한 하이브리드 선택 알고리즘이 잘 작동함.

### 5️⃣ 대형 우클릭 이동 및 미세 정착 실험 (`Squad.cs` & `PlayerController.cs`)
- **실험 방법**: 유닛 선택 후 원하는 지점에 우클릭 드래그로 이동 명령을 전달.
- **기대 결과**: 유닛들이 오열 간격(`0.6f`)을 지키며 대형을 유지한 채 지정 위치로 이동하고, 정착 시 미세 보정으로 깔끔하게 정렬됨.
- **실험 결과**: **`O` (성공)**
- **세부 설명**: `AssignFormationPositions`와 도착 직후 0.05f 전진하는 `HandleSquadMicroAdjustment`가 의도대로 실행됨.

### 6️⃣ Ctrl + 좌클릭 고정 대형 이동 실험 (`PlayerController.cs`)
- **실험 방법**: 부대가 선택된 상태에서 `Ctrl` 키를 누른 채 마우스 좌클릭 드래그.
- **기대 결과**: 부대의 기존 회전각과 가로 폭이 유지된 상태로, 마우스 위치가 대형의 정중앙에 위치하도록 프리뷰가 그려지고 이동함.
- **실험 결과**: **`O` (성공)**
- **세부 설명**: `DrawFixedCenteredPreview` 메서드가 완벽하게 중앙 오프셋을 계산하여 지시함.

### 7️⃣ Shift / Ctrl + 우클릭 경로 예약 실험 (`Squad.cs`)
- **실험 방법**: `Shift + 우클릭`으로 여러 경유지를 찍어 이동 명령 입력.
- **기대 결과**: 지점들이 초록색 라인(`WaypointLineRenderer`)으로 연결되며, 첫 번째 목적지 도착 시 다음 경유지로 자동 이동함.
- **실험 결과**: **`O` (성공)**
- **세부 설명**: `waypointList` 큐(Queue) 연동 및 `IsSquadFullyArrived` 판정이 안정적으로 수행됨.

### 8️⃣ 부대 지정 실험 (`PlayerController.cs`)
- **실험 방법**: 유닛을 선택한 상태에서 `Shift + 1`을 눌러 등록한 후, 빈 곳을 클릭해 선택을 해제했다가 `1` 키를 누름.
- **기대 결과**: 1번 키를 누르는 즉시 아까 지정했던 부대 유닛들이 전원 재선택됨.
- **실험 결과**: **`O` (성공)**
- **세부 설명**: `controlGroups` 딕셔너리에 정상 기록 및 핫키 호출 성공.

### 9️⃣ 개별 병사 3초 자율 대형 복귀 실험 (`Soldier2D.cs`)
- **실험 방법**: 전투 중이거나 밀쳐져서 대형에서 0.25m 이상 벗어난 병사를 방치.
- **기대 결과**: 3초(`reformDelay`) 동안 재배치가 없으면 해당 병사가 스스로 부대 지정 좌표로 복귀함.
- **실험 결과**: **`O` (성공)**
- **세부 설명**: `HandleIndividualAutoReform` 타이머 및 `reformThreshold` 조건 정상 판단.

🔟 **Kinematic 밀어내기 충돌 실험 (`Soldier2D.cs`)**
- **실험 방법**: 유닛들이 좁은 공간에 뭉쳤을 때 서로 물리적으로 겹치는지 확인.
- **기대 결과**: 유닛끼리 겹치면 반대 방향으로 푸시 포스(`pushForce = 3.0f`)가 적용되어 서서히 밀려나 자리를 확보함.
- **실험 결과**: **`O` (성공)**
- **세부 설명**: `FixedUpdate` 내 `OverlapCircleAll` 연산과 정지/이동 유닛 가중치 부여 완벽 작동.

1️⃣1️⃣ **적 AI 탐색 및 근접 전투 실험 (`Soldier2D.cs`)**
- **실험 방법**: 플레이어 부대와 적 부대가 근접했을 때 동작 관찰.
- **기대 결과**: 적 유닛이 0.2초 간격으로 가장 가까운 아군을 추적하며, 닿으면 1초 마다 데미지를 주어 체력이 0이 된 유닛은 파괴됨.
- **실험 결과**: **`O` (성공)**
- **세부 설명**: `FindClosestEnemy` 및 `OnTriggerStay2D` 공격 쿨타임 로직 정상 실행.

1️⃣2️⃣ **월드 공간 부대 UI 실험 (`SquadIconUI.cs`)**
- **실험 방법**: 부대가 이동할 때 머리 위 하늘색 UI 아이콘의 움직임 관찰 및 아이콘 마우스 클릭.
- **기대 결과**: UI가 부대 중심을 잘 따라다니며, 아이콘 클릭 시 부대 전체가 선택됨. 부대가 파괴되면 UI도 자동 제거됨.
- **실험 결과**: **`O` (성공)**
- **세부 설명**: World Space Canvas 연동 및 `IPointerDownHandler` 클릭 이벤트 정상 작동.


- **검증 내용**: 
  - Unity CLI를 통한 배치 실행 결과, 현재 사용자의 시스템에서 **Unity 6000.3.18f1 에디터가 본 `MiniTotalWar2D` 프로젝트를 점유하고 정상 구동 중임**을 실시간으로 확인하였습니다.
