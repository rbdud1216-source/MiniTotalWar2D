# 언어 및 문서화 규칙 (Language & Documentation Rules)

## 1. 대화 및 응답 (Communication)
- 사용자와의 모든 대화, 작업 보고서, 계획서 및 설명은 **한국어**로 작성합니다.
- **작업 소요 시간 명시**: 개발 작업 및 코드 수정을 완료하고 보고할 때, 답변 상단이나 요약부에 총 소요 시간(예: `⏱️ 소요 시간: 약 15초` 또는 `⏱️ 소요 시간: 약 1분 20초`)을 간단하게 한 줄로 명시합니다.

## 2. 🚨 도구 실행 승인 및 권한 요청 한국어화 (Tool Permission & Confirmation)
- 에이전트가 파일 수정, 터미널 명령어 실행, 빌드 등 도구를 호출할 때 사용자에게 승인/허가를 묻는 팝업창의 제목과 설명(`toolAction`, `toolSummary`)은 **반드시 100% 명확하고 자연스러운 한국어로 작성**합니다.
- 예시:
  - `Git 상태 확인`
  - `미니맵 스크립트 수정`
  - `유니티 컴파일 결과 검증`

## 3. 🚫 LaTeX 수식 및 과도한 마크다운 서식 금지 (Clean Text Rule)
- **LaTeX 수식 문법 사용 완전 금지**: `$\rightarrow$` 같은 수식 태그를 일절 쓰지 말고, 일반 화살표 문자(`→`, `->`)를 사용합니다.
- **깔끔하고 눈이 편한 서식**: 복사나 가독성을 해치는 과도한 볼드(`**`)나 백틱(`` ` ``) 남발을 피하고, 자연스럽고 깔끔한 문장으로 작성합니다.

## 4. 코드 주석 (Code Comments)
- 새로 작성하거나 수정하는 코드 내의 모든 주석(인라인 주석, 요약 주석, XML 문서화 등)은 **한국어**로 작성합니다.

## 5. 외국어 및 전문 기술 용어 병기 (Glossary)
- 영문 기술 용어, 고유 명사, API 명칭 등 외국어 표현이 필요한 경우, 적절한 한국어 표현을 주 표기로 사용하고 괄호 `()` 또는 설명을 덧붙여 병기합니다.
  - 예시:
    - `개체-컴포넌트 시스템 (ECS, Entity Component System)`
    - `작업 시스템 (Job System)`
    - `네비메시 (NavMesh, 내비게이션 메시)`
    - `인스턴싱 (GPU Instancing)`
    - `동기화 (Synchronization)`

## 6. 작업 로그 및 문서화 (Docs WorkLog)
- 모든 작업 히스토리, 변경 내역, 시스템 구조는 `Docs/` 디렉터리(`Docs/업데이트_내용.md` 및 해당 스크립트 문서)에 한국어로 기록하고 최신 상태를 유지합니다.
